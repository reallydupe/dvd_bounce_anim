**DVD Logo bouncing animation, py**

This was made in python without any AI
Feel free to mod this to add things you want

What this was made on and what libraries used:
Tkinter (The window and responsible for all the window logic), built-in library
pywinstyles (just a hefty thing that lets you apply windows themes, but here its used to  change the window's titlebar color to black), to install use: <pre><code>pip install pywinstyles</code></pre>
random (Used to randomly pick colors), built-in library

What libs you could use in the future:
PIL (pillow), - Can be used to replace the square with an actual dvd logo and change its color, to install use: <pre><code>pip install pillow</code></pre>
